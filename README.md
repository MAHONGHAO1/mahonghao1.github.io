# mahonghao1.github.io

具身智能数据工程作品集。纯静态页面，GitHub Pages 托管，不起后端。

**在线**：<https://mahonghao1.github.io/>

## 里面有什么

| 路径 | 内容 |
| --- | --- |
| `/` | 首页：两个公开项目加两套内部系统，每张卡片都能点进验收证据 |
| `/robodata/` | RoboData Workbench 深度页：四路相机同步时间轴（8 个时刻 × 4 路，可拖动）、九个界面视角、证据链与能力边界 |
| `/demo/` | 基金观察离线演示：固定净值快照，只读点按，不用装 Python |
| `resume-mahonghao.pdf` | 简历 |

## 为什么值得点开

**如果你想知道「这活到底干得怎么样」**，别看我怎么说，看时间轴。`/robodata/` 里那 8 个时刻，每一帧都是从通过验收的交付包里四路 H.264 按**相同帧索引**解码后拼起来的，不是录屏，也不是示意图。四路都有画面、帧号与时间对得上，这是能被别人当场核对的。

**如果你只是想看看界面长什么样**，`/demo/` 里的基金工作台可以直接点，不用装任何东西。

**如果你想找漏洞**，页面上写着每条主张的证据在哪、以及哪些事**没有**验证（比如四路同屏只是布局验证，不代表相机硬件同步；标注审核是脚本模拟的，不是人工审核）。这些不是免责声明，是可以拿去追问的清单。
